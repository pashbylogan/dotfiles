Decision Log

Decisions & rationale

Every load-bearing choice, with the reason it was made. Each has a stable ID (see Trace); the D-ID tags below are grep targets.

Core architecture

DecisionChoiceWhy
D-ENGINE Convergence engine Lightweight shell + Omarchy CLI + stow. No Ansible, no dot-apply/check/update/cleanup engine. Omarchy already does install/seed/migrate/update. A convergence framework would re-implement that and accrue code that must survive upstream churn.
D-SCRIPTS-MINIMAL Scripts One script: install. No update/cleanup scripts. Owner chose pure-minimal. Updates run via omarchy update -y; one-time i3/zsh cleanup is a documented manual step.
D-DELTA-STORAGE Delta storage Own thin fragments + single managed integration block. Never symlink Omarchy-owned files. (Full detail: Architecture.) Omarchy cp-resets write through symlinks (F-REFRESH-WRITETHROUGH); owning whole files freezes them and breaks on the coming Lua move (F-LUA).

Shell

DecisionChoiceWhy
D-SHELL-BASH Login shell bash (Omarchy default). No chsh to zsh. Omarchy's boot/session/helpers assume bash; chsh→zsh is a documented footgun (F-SHELL-RESEARCH). Omarchy's bash already wires starship/zoxide/fzf/mise, so zsh's marginal gain is small.
D-SHELL-SEAM Aliases/functions Ported into ~/.config/dotfiles/shell.sh, sourced via the ~/.bashrc managed block (at EOF, so ours win). ~/.bashrc is owner-owned and "not overwritten on updates" (F-BASH-CHAIN). Aliases Omarchy already defines (t, g, gcm, gcam, n, cd/zoxide, ls/eza) are dropped in favor of Omarchy's.
D-SECRETS-LOCAL Secrets/host-specific Gitignored shell.local.sh (Vertex project IDs, device serials). Keep the shared repo generic and secret-free.

Baseline & bindings.conf D-BASELINE

Reference baseline = "Omarchy after Remove Preinstalled" The owner's first step was running Remove Preinstalled, which stripped bundled apps and their launcher bindings (F-BASELINE). So the trimmed ~/.config/hypr/bindings.conf is intentional, not drift. We leave it Omarchy-owned and untracked; we do not restore it to vanilla stock. Reproduction recipe: install → Remove Preinstalled → ./install.
