Traceability

Change-impact index

Every design decision (D-*) and research finding (F-*) has a stable, grep-able ID. This page mirrors registry.json (the machine-readable source of truth) so a human or agent can see, at a glance, where each idea lives and what it governs.

How to use this when something changes
  1. Grep the ID across the repo (e.g. grep -rn D-DELTA-STORAGE) — it appears in docs, in registry.json, and as a [D-DELTA-STORAGE] token in the governing code's comments.
  2. Or open registry.json and read the entry's code_paths + appears_in — that is the authoritative "update these places" list.
  3. Update the canonical doc section, every listed doc/code touchpoint, and the registry entry itself.
