A minimal personal overlay on Omarchy

This repo does not rebuild a desktop. Omarchy installs and seeds everything; this repo layers only the owner's intentional customizations on top, using official Omarchy paths and a single idempotent install script.

Start here (future agents) Read Architecture for the ownership model and the one rule that governs everything: never symlink an Omarchy-owned mutable file into git — own a thin fragment and integrate it with a single managed block. Then skim Decisions for the "why", and To-Dos for what's done and what's next.

The repo at a glance

dotfiles/
├── AGENTS.md                    # concise agent guidance + comment conventions
├── install                      # the ONLY runtime script — stow + managed blocks + dev-env reconcile + XDG (idempotent)
├── Makefile                     # `make ci|fmt|tools|update|verify` — single ops interface; CI invokes `make ci`
├── packages.txt                 # extras → omarchy pkg add
├── packages.aur.txt             # AUR extras → omarchy pkg aur add (slack/spotify/jetbrains-toolbox)
├── bash/.config/dotfiles/       # shell.sh (ported aliases) + shell.local.sh.example
├── ssh/.ssh/                    # config (+ Include config.local) + config.local.example
├── bin/.local/bin/              # personal commands → ~/.local/bin (on PATH)
├── tmux/.config/tmux/local.conf  # tmux overlay (source-file'd from omarchy's tmux.conf)
├── hypr/.config/dotfiles/       # hypr.conf override fragment + hypr.local.conf.example
├── docs/                        # this knowledge base
└── .github/                     # CI workflow + scripts/check_docs.py (docs gate) + scripts/verify.sh (live gate)
Reproduction recipe Install Omarchy → run Remove Preinstalled (omarchy menu) → ./install. The "after Remove Preinstalled" state is this repo's reference baseline — see Findings → Baseline.
